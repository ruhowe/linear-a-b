# Corazza, Ferrara, Montecchi, Tamburini, Valério (2021), *The mathematical values of fraction signs in the Linear A script*

J. Archaeological Science 125.

## What it claims

Exhaustive constraint search over ~4M value assignments pruned by tablet totals, plus typological comparison. Coherent system with lowest value 1/60; the Linear A 1/10 sign continues as a Linear B dry measure. NO phonetic values used.

## Our assessment

Verification **P**. We have only seen this restated elsewhere, in a review, index record or later paper. Re-verify before citing it in print.

THE ONLY accepted computational result on Linear A itself, and there is no implementation of it anywhere. The load-bearing positive control for any evaluation harness — and the sign-by-sign table is behind a 403.

# Wyatt (1976), review of Packard, *Minoan Linear A*

William W. Wyatt Jr., Brown University. *The Classical World* 69(5), February 1976, 336–337.

## What it claims

Summarises Packard's two classes of evidence for carrying Linear B sound values over to Linear A: alternations inside Linear A, and matches with personal names at Knossos, both checked against ten random decipherments. "There are significantly more matches if Linear B values are assigned than with any of the random decipherments. I find his results convincing." Also: classification "becomes necessary only a) when it is obvious, and b) where there is a large corpus: neither condition applies with Linear A". Closes: "Packard's work will be basic to any future decipherment of Linear A."

## Our assessment

Verification **Y**. Read in full from JSTOR on 2026-09-11.

Shows how Packard's result was received: accepted, and read as one result. Packard himself separated the two classes. The names beat every random set; the alternations did not do so clearly (pp. 76–80, 93). Wyatt's summary merges them, which may be where later accounts of a single "2:1" ratio come from. No new measurement.

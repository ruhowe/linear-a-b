# Perono Cacciafoco, Eu, Loh, Yao, Cavallaro (2019), *Linear A decipherment programme (NTU, MOE grant)*

Annals Univ. Craiova; Fluxus Grapholinguistics.

## What it claims

Python matching of CSV dictionaries against a Linear A word list using vowel-stripped consonantal skeletons on Linear B values; Semitic and Egyptian lexica tried.

## Where to find it

- [fluxus-editions.fr/gla5-cacc.pdf](https://fluxus-editions.fr/gla5-cacc.pdf)
- Access: **open**

## Our assessment

Verification **Y**. We fetched and read the primary source.

Authors report results inconclusive themselves; found 'very little in common' with Semitic on the libation tables. Not fringe, but exhaustive dictionary matching guarantees hits — precisely what our null test prices.

Added 2026-09-11 (prior-art search): Fang, Perono Cacciafoco and Cavallaro (2021), "Some Remarks on Grammatological and Morphological Aspects of Linear A Documents", Analele Universitatii din Craiova 43(1-2), identifies recurring clusters and derives "an approximate morphological breakdown of the clusters", descriptively, with no statistical test (verified P, secondary only).

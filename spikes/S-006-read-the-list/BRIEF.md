# S-006 · Read the Linear A list anyway: the ranked alternations beside the field's by-eye findings

**Question.** The Kober instrument's Linear A ranking (0.7 on Linear A, F-033; 0.9,
F-040) is a list of sign-label alternations with supports at or near their null. The
field has by-eye morphological proposals: the ja-sa-sa-ra-me family, the -ti/-si and -ja/
-jo alternations discussed by Duhoux, Facchetti's ja-/a- prefixes, Younger's suffix list.
Laid side by side, labelled, do the instrument's top pairs coincide with any of them?

**Why a spike.** It is reading, not testing: the ranking's supports are at the null, so
agreement with the field would say only that the machine and the eye see the same few
recurrences, and disagreement would say nothing. The value is documentary: a table that
anyone in the field can look at and recognise, which the repository does not yet have.

**Method.** The top twenty ending-channel and prefix-channel alternations from
`results/kober-09/kober-lineara-seed0.json` as sign labels with supports and null
percentiles; beside each, whether it appears in Younger's suffix list, Duhoux 1978 to
1998, Facchetti 1999b, Schoep 2002 or Davis 2014 (from `docs/works/` and the
sources; cite the page). Aggregate only in the repo: the table carries sign labels, not
words.

**Interesting.** More than half of the top ten are proposals the field has already made
by eye, each with its page. **Nothing.** Fewer than half; or the field's proposals sit
below the top twenty, which would be worth its own line.

**Must not be read as.** Support for any proposal. Supports at the null are at the null
whoever else has noticed the pair.

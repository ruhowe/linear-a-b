# Kim, Snyder (2013), *Unsupervised Consonant-Vowel Prediction over Hundreds of Languages*

ACL 2013.

## What it claims

"Average accuracy in the unsupervised consonant/vowel prediction task of 99% across 503
languages", using a hierarchical Bayesian model with typological priors from known languages.

## Where to find it

- [aclanthology.org/P13-1150](https://aclanthology.org/P13-1150/)
- Access: **open**

## Our assessment

Verification **Y**. We fetched and read the primary source.

The nearest computational analogue to recovering a syllabic grid from distribution. It uses
cross-language priors, so it is lineage for the repo's C-3b, not a precedent on Linear B.

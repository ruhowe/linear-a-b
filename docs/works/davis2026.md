# Davis (2026), *The Undeciphered Aegean Scripts*

Cambridge University Press, 530 pp..

## What it claims

'Syllabotactic analysis': system-internal sign-position constraints, validated against Linear B and Cypriot as controls. Linear A is not Greek; Linear A and Cypro-Minoan encode different languages.

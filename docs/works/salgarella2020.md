# Salgarella (2020), *Aegean Linear Script(s): Rethinking the Relationship between Linear A and Linear B*

Cambridge University Press.

## What it claims

Palaeographic and structural model: gradual continuity, 'a single Aegean Linear Script'; regional Linear A variants carried into Linear B.

## Where to find it

- DOI [10.1017/9781108783477](https://doi.org/10.1017/9781108783477)

## Our assessment

Verification **P**. We have only seen this restated elsewhere, in a review, index record or later paper. Re-verify before citing it in print.

Nash (BMCR 2021.04.30) objects that metrology, layout and logogram changes show deliberate reform, not continuity. Her numeric homomorph counts not retrievable.

# Sproat (2014), *Critiques of the entropic-evidence argument (CL Last Words; Language 90(2))*

Computational Linguistics 36(3); Language 90(2).

## What it claims

The entropy test is non-discriminating: non-linguistic control corpora (deity symbols, heraldry, weather icons, emoticons) score the same. Rao concedes entropy does not prove language.

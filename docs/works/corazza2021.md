# Corazza, Ferrara, Montecchi, Tamburini, Valério (2021), *The mathematical values of fraction signs in the Linear A script: A computational, statistical and typological approach*

J. Archaeological Science 125, article 105214. The title on this page previously omitted
the subtitle, and the venue gave no article number; both are corrected from Crossref.

## What it claims

Exhaustive constraint search over ~4M value assignments pruned by tablet totals, plus typological comparison. Coherent system with lowest value 1/60; the Linear A 1/10 sign continues as a Linear B dry measure. NO phonetic values used. These specific figures (the ~4M count, the 1/60 lowest value, and the Linear B dry-measure continuation) are not confirmed from the primary, 2026-09-13.

## Our assessment

Verification **P**. We have only seen this restated elsewhere, in a review, index record or later paper. Re-verify before citing it in print.

THE ONLY accepted computational result on Linear A itself, and there is no implementation of it anywhere. The load-bearing positive control for any evaluation harness — and the sign-by-sign table is behind a 403.

Checked 2026-09-13: confirmed full title, author order and article number via Crossref, and
confirmed via Unpaywall that the paper is genuine hybrid open access (CC BY-NC-ND,
publisher's version). Despite that, ScienceDirect, the University of Florence repository
(two separate URLs) and the University of Bologna repository all refused our fetch and
curl attempts with a 403 or a Cloudflare challenge, so we could not read the full text or
confirm the specific figures in "What it claims" from the primary. Semantic Scholar's
abstract confirms only the general method (paleographic, statistical, computational and
typological analysis of fraction-sign values) and the general finding (a systematic value
assignment), not the ~4M figure, the 1/60 value, or the dry-measure claim.

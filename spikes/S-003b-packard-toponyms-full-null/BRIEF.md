# S-003b · Packard's toponym evidence, values permuted at every position

**Question.** Packard 1974's strongest evidence for the transferred sound values was not
internal alternation but the Knossos place names: 13 three-sign matches between Linear A
sign-groups and Linear B toponyms under Linear B values, against 3 by chance (Table 14).
Does that survive a frequency-banded value-permutation null with 200 draws rather than
nine, the current GORILA corpus, and the SigLA edition?

**The corrected null.** S-003 ran this test but fixed the first two sign positions of
every candidate match as a "corpus fact" and let only the third position's consonant
vary under the null. That is wrong: label identity between a Linear A sign and a Linear
B sign *is* the value transfer under test, so fixing it handed the null most of the real
count before a single draw was taken (3.17 of a real 5 on GORILA, S-003's own numbers).
S-003b instead builds an explicit value assignment, a map from every Linear A label
eligible for a value (see below) to a Linear B label. The real assignment is identity,
the transliteration convention. A null assignment permutes labels within a
frequency band, Packard's own construction (p. 73-74: signs sorted by frequency into
groups of ten, values reassigned within each group), so a common sign cannot trade
places with a rare one, but every position of every word is read through whichever
assignment is current, real or null. A match now has to earn all of its identical
positions under the null, exactly as it does under the real assignment.

**Why a spike.** It is the etymological method with a lexicon of about sixty Linear B
toponyms, and the main line closed that method. But toponyms are the one lexicon with a
mechanism (place names persist across a language change), it is the argument the field
actually relies on for A-001, and S-003's own null was too weak to read the question at
all.

**Interesting.** The real toponym match count clears the null's 99th percentile on both
editions, and the personal-name control does not. **Nothing.** Otherwise: the real count
sits inside the null distribution on either edition, or the control also clears its own
99th percentile.

**Must not be read as.** Support for any value set beyond the toponym matches
themselves, or for any language of Linear A. The match criterion here is literal label
identity; Packard's own hand-collected matches admitted looser parallels (docs/works/packard1974.md),
so a "nothing" result bounds this specific, stricter construction, not his.

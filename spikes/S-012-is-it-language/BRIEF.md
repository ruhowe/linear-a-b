# S-012 · Is Linear A writing language at all, by the Indus-debate measures

**Question.** The Indus script debate (Rao 2009 against Sproat 2014, both catalogued)
asked whether a sign system encodes language, using conditional entropy and related
measures on sign sequences, and the answer depended on which non-linguistic systems were
used as references. Linear A is assumed to write a language. Where does it fall by those
measures, with Linear B as the positive control that the Indus debate lacked?

**Why a spike.** The question sounds absurd for an accounting script with numerals and
totals. That is why it is cheap and safe to ask: the expected answer is "language", and
the value is that Linear B shows what "language" looks like in the same script family at
the same size, which no Indus study could show.

**Method.** Rao's block entropy and conditional entropy curves; Sproat's objections
(sequence length, sample size, the choice of non-linguistic references) answered by using
Linear B subsampled to Linear A's size as the linguistic reference and, as non-linguistic
references, sequences that are provably not language: shuffled Linear B (destroys
sequence), sign sequences from a non-linguistic sign system with an open corpus if one is
reachable (heraldic blazon strings, DNA codons at a sign-inventory of 64), and synthetic
Markov sequences fitted to Linear A's unigram frequencies.

**Interesting.** Linear A sits with the non-linguistic references rather than with
Linear B by more than the noise floor: worth a hard look at whether the measure or the
corpus is at fault, before any other reading. **Nothing.** Linear A sits with Linear B:
expected, and it gives the Indus debate a calibration point it never had.

**Must not be read as.** Anything about which language.

# S-003 · Packard's toponym evidence under a modern null

**Question.** Packard 1974's strongest evidence for the transferred sound values was not
internal alternation but the Knossos place names: 13 three-sign matches between Linear A
sign-groups and Linear B toponyms under Linear B values, against 3 by chance (Table 14).
Does that survive a frequency-banded value-rotation null with 200 draws rather than nine,
the breadth-matching F-004 found necessary, the current GORILA corpus, and the SigLA
edition?

**Why a spike.** It is the etymological method with a lexicon of about sixty Linear B
toponyms, and the main line closed that method. But toponyms are the one lexicon with a
mechanism (place names persist across a language change), it is the argument the field
actually relies on for A-001, and nobody has rerun it with a proper null in fifty years.

**Interesting.** The match count sits above the null's 99th percentile on both editions:
the toponym argument for some transferred values holds up, and A-001 gains its first
positive test. **Nothing.** It sits inside the null: Packard's nine rotations were too
few, and the toponym argument is weaker than the field assumes.

**Must not be read as.** Support for any value set beyond the toponym matches
themselves, or for any language of Linear A.

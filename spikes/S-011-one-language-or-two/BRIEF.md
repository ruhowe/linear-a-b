# S-011 · One language in Linear A, or two?

**Question.** Linear A's material falls into an administrative archive (Hagia Triada
and the other tablets, transactions and lists) and a religious set (libation tables,
vessels, the formula texts). Kober 1948 noted Linear A is not homogeneous
geographically or chronologically except at Hagia Triada. Do the two sets share one
sign-statistical profile, or two?

**Why a spike.** Nothing in the main line asks it; every Linear A run pools the corpus.
If the two sets differ as much as two languages in one script would, the pooled
statements in F-019 to F-023 are about a mixture.

**Method.** Split Linear A word tokens by support type (tablet against stone vessel and
other) and by site. For each subset: sign frequency profile, positional profile, word
length, and the stage 1 paradigm ratio against its own N1. Distance between subsets.
Control for "same language, different genre and site": Linear B split the same ways
(Knossos against Pylos; livestock series against personnel series), which gives the
spread one language produces across genres. A second control for "two languages": Linear
B against Cypriot syllabic Greek is still one language; Linear B against Ugaritic is
two, in different scripts, so use it only as an outer bound.

**Interesting.** The Linear A archive-against-religious distance exceeds Linear B's
genre and site spread by more than the subsample noise. **Nothing.** It sits inside that
spread.

**Must not be read as.** Evidence for any particular language in either set.

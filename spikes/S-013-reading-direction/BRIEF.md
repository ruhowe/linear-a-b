# S-013 · Reading direction: does any support type's structure improve if reversed?

**Question.** Kober 1948 says Linear A reads uniformly left to right; earlier scripts
varied and the seal-stones read in either direction. If some support type (seals,
vessels, roundels) were read the wrong way in the transcription chain, its words would
be reversed relative to the tablets, and stem-and-ending structure across the corpus
would be weakened. Does reversing any support type's words raise the pooled paradigm
ratio above what the unreversed corpus gives, beyond the N1 spread?

**Why a spike.** A perturbation test with a known answer on Linear B (nothing should
improve) and a cheap run on Linear A.

**Interesting.** One support type's reversal raises the ratio beyond the spread on
Linear A and no type does on Linear B. **Nothing.** No reversal helps on either.

**Must not be read as.** A claim about the direction of any inscription; only a
consistency check on the transcription.

# S-001 · Mirror Linear B: a positive control for the prefix channel

**Question.** The Kober instrument's prefix channel has no positive control, because
Greek prefixes little (A-040). If every Linear B word is reversed, its suffixes become
prefixes. Does the prefix channel then recover Greek grammar from the mirrored corpus as
well as the ending channel does from the real one?

**Why a spike.** It is a synthetic corpus, and the main line does not run synthetic
positive controls (F-004 is the record of why). But the transform is exact, involves no
values, and answers a question the main line could not: whether a null prefix result on
Linear A (F-019) is a property of the corpus or of a channel that cannot see prefixes.

**Interesting.** The mirrored ending channel and the real prefix channel agree in
paradigm count, top alternations and grammar match to within the null's spread: the
prefix channel works, and F-019's prefix null on Linear A means Linear A does not prefix
visibly. **Nothing.** They disagree: the prefix channel has a defect (A-047 found one
already), to be fixed as a version before any prefix statement is repeated.

**Must not be read as.** Anything about Linear A. It is a test of the instrument.

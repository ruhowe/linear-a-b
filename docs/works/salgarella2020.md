# Salgarella (2020), *Aegean Linear Script(s): Rethinking the Relationship between Linear A and Linear B*

Cambridge University Press, 436 pp. ISBN 9781108479387 (hardback).

## What it claims

Palaeographic and structural model: gradual continuity, 'a single Aegean Linear Script'; regional Linear A variants carried into Linear B.

## Where to find it

- DOI [10.1017/9781108783477](https://doi.org/10.1017/9781108783477)
- Publisher page: [cambridge.org/core/books/aegean-linear-scripts](https://www.cambridge.org/core/books/aegean-linear-scripts/FC37E828162236D889642BAC72099A9C)
- Access: **paywalled**. No open access edition found.

## Our assessment

Checked 2026-09-13: could not reach the primary text. Confirmed title, author, publisher and
page count via Cambridge Core and a Classical Review notice of the book. Confirmed the review
citation against the actual review text: Theodore Nash (BMCR 2021.04.30) does object that
"significant structural changes in the use of signs," "entirely different systems of weights and
measures," and "distinct tablet layouts" point to "a deliberate programme of script reform"
rather than the continuity Salgarella argues for, matching the page. The claim "her numeric
homomorph counts not retrievable" is not confirmed from the primary, 2026-09-13: Nash's review
does not discuss numeric homomorphs, and no other accessible source does either, so this could
be either an editorial note about the book itself or a stray claim; it needs checking against
the book directly. The flag stays **P**.

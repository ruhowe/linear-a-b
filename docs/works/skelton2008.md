# Skelton (2008), *Methods of using phylogenetic systematics to reconstruct the history of the Linear B script*

Archaeometry 50(1), 158–176. The page range was missing from this page and is added from Crossref.

## What it claims

Cladistics applied to scribal hands: hands as taxa, sign-form variants as characters, parsimony via PAUP*. The specific use of PAUP* is not confirmed from the primary, 2026-09-13.

## Our assessment

Verification **P**. We have only seen this restated elsewhere, in a review, index record or later paper. Re-verify before citing it in print.

Checked 2026-09-13: confirmed title, sole authorship and the page range (158-176) via
Crossref. The author's own site (christinaskelton.com) lists this paper with matching
title, venue and pages, and offers the underlying NEXUS dataset ("LinearB.nex", "from
Skelton 2008") for download, but no PDF of the paper itself. Wiley's Archaeometry page,
Academia.edu and ResearchGate were not reached within this check's budget. The general
method description (cladistics, hands as taxa, sign-form variants as characters) matches
independent search summaries of the paper, but the specific detail that PAUP* was the
software used is not confirmed from the primary.

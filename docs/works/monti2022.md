# Monti (2022), *Some observations on the language of Linear A*

Kadmos 61(1-2): 107–116.

## What it claims

The sequence -i-*301- in a-ta-i-*301-wa-ja and its variants is probably a verbal root. The
alternation a-/ja- seen in a-sa-sa-ra-me/ja-sa-sa-ra-me is attributed to a prefix i-/j-, which
probably functions as an article, with i-na- as its plural. The term (j)a-sa-sa-ra-me probably
means "gift" or "homage", not "sacred" and not "offering". Also from the abstract: the language of Linear A is probably only one (§ 1), and
arguments already put forward suggest it is probably neither Indo-European nor Semitic, nor an
ergative language such as Hurro-Urartian (§ 7).

re-read by the session on 2026-09-13, which corrected this agent's first note that the last of

# S-010 · What kind of script is Linear A? Syllabary, logographic, or Egyptian-like

**Question.** Everything in the main line assumes Linear A is a consonant-vowel
syllabary like Linear B (A-040; Kober 1948's Cypriote assumption, stated by her as
unproven). Two alternatives Ru raised: that it is closer to Egyptian hieroglyphic, a
mixed system of logograms, consonantal phonograms and determinatives with no vowels; or
that each sign is a whole word. Can sign statistics alone, with no values, say which
kind of system it is?

**Why a spike.** It is a typological question the field treats as settled by Linear B's
descent from Linear A, and Ventris and Chadwick themselves say the derivation is "a
radical adaptation" (Bennett, quoted p. 37). Kober 1948, p. 103: "the type of syllabary
used cannot be determined until we know how many signs were used phonetically."

**Method.** Compute, for Linear A and for reference corpora of known type, the
statistics that distinguish script types without values: inventory size and how it
grows with corpus size (Heaps curve); word-length distribution in signs; sign frequency
distribution shape and the share of hapax signs; positional entropy (first, medial,
last sign); conditional entropy of sign bigrams (Rao 2009, with Sproat 2014's caveats);
and the Kober-grid signature, the degree to which alternating signs cluster into
classes, which a CV syllabary shows and a logographic system does not. References:
Linear B (CV syllabary, known); Cypriot syllabic Greek if a transliterated corpus is
reachable; Ugaritic (consonantal alphabet, cached corpus); Sumerian and Akkadian
cuneiform from ORACC (logosyllabic, CC BY); Egyptian hieroglyphic from an open
transliterated corpus if one is reachable under licence (Ramses, TLA), else
Middle Egyptian sign-level text from an open textbook corpus; Chinese from any open text
(logographic). Each reference is subsampled to Linear A's size, twenty times, so size is
not the discriminator. Distance from Linear A to each reference's profile, with Linear
B's distance to its own subsamples as the noise floor.

**Interesting.** Linear A sits nearest a non-syllabic reference by a margin larger than
the noise floor: the base assumption of every structural test here is in question and
the main line's limits section needs a new row. Or: Linear A sits nearest Linear B by
that margin, and "each sign is a word" is excluded by the same numbers (a logographic
system's words are one sign long; Linear A's average three to four).

**Nothing.** Linear A is equidistant from several references, or the references' own
subsamples spread as widely as the differences: the statistics cannot decide type at
this corpus size, which is itself worth one line.

**Must not be read as.** A statement about the language. Script type and language are
independent (Kober 1948, p. 101).

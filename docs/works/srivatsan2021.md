# Srivatsan, Vega, Skelton, Berg-Kirkpatrick (2021), *Neural Representation Learning for Scribal Hands of Linear B*

ICDAR WS Computational Palaeography, LNCS 325–338.

## What it claims

Disentangled scribe + sign embeddings from 4,134 glyph images, 88 signs, 74 hands. Findplace F1 0.292 vs autoencoder 0.234 vs majority 0.154.

- [arXiv:2108.04199](https://arxiv.org/abs/2108.04199)
